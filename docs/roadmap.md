# 📋 Echo 小米 MIX 2 智能桌面伴侣 & 宿舍私有服务器 · 全景演化路线图 (Master Roadmap)

> **硬件载体**：小米 MIX 2（高通骁龙 835 / 6GB LPDDR4x / 18:9 全贴合 IPS 屏 / 黑色陶瓷机身）  
> **核心定位**：24/7 宿舍全天候静音私人服务器 + 桌面纯正日系暗夜手帐 Live2D 陪伴终端  
> **四大设计铁律**：
> 1. **物理硬件价值最大化**：榨干骁龙 835 算力、6GB 运存、IPS 零烧屏、右下角前置仰角镜头、光线传感器与局域网跳板能力；
> 2. **极致静音与零光污染**：适应宿舍集体生活，白天安静伴读，熄灯（<5 Lux）瞬间彻底黑屏断电休眠，严禁扬声器噪音扰民；
> 3. **边缘看门 + 云端心智**：本地 OpenCV（30ms SFace/YuNet 人脸初筛）实现 0 Token 高帧率守护；多模态 VLM 与 DeepSeek 仅在关键时刻提供高灵性心智共振；
> 4. **绝对隐私底线**：严禁无节制截屏电脑桌面，仅采集前台窗口元数据；前置抓拍未命中即刻内存销毁，绝对不落盘。
