## 当前能力

- 手机可独立运行 AstrBot、DeepSeek 对话、联网搜索、记忆和表情插件。

- USB 只用于 ADB 调试和 WebUI 转发，不再是手机运行 AstrBot 或连接 MCP 的必要条件。

## 安全边界

- 手机 WebUI 未向局域网或 ZeroTier 暴露。
- 电脑 MCP 使用 Bearer token，Windows 防火墙仅允许手机 ZeroTier 地址访问 `8765`。
- MCP 仅开放三个低风险工具，执行工作区受目录白名单限制。
- APK、运行数据、数据库、备份、用户记忆和密钥均不提交到 GitHub。
