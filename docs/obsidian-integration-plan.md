# Obsidian 集成

## 目标

让手机端 echo 通过电脑 MCP 只读检索 `D:\wenboo`，同时保持 Vault 为唯一主副本。

第一阶段只提供搜索、列目录和读取命中片段；不修改任何 Obsidian 文件，不调用 Git，不读取附件。

## 已确认的隐私边界

| 内容 | 私聊 | 群聊 | 索引 |
|---|---:|---:|---:|
| 密码、Token、密钥、恢复码 | 禁止 | 禁止 | 禁止 |
| 日记 | 仅按需 | 禁止 | 不建立常驻索引 |
| 简历、入党材料、面试记录、个人计划 | 仅按需 | 禁止 | 不建立常驻索引 |
| 项目、科研、课程笔记 | 允许 | 禁止 | 允许 |
| 归档 | 明确要求时 | 禁止 | 默认不索引 |
| 附件、图片、`.obsidian`、`.git` | 禁止 | 禁止 | 禁止 |

“按需”指用户在 QQ 私聊中明确提及日记、日期、个人计划或相关主题；普通聊天不主动检索这些内容。

## 路径策略

默认可搜索：

- `1. Projects/`
- `3. Resources/`
- `5. Note/`

按需可搜索：

- `2. Areas/日记/`
- `2. Areas/` 中的个人计划与长期领域笔记
- `4. Archives/`

永久排除：

- `.obsidian/`
- `.git/`
- `.wenbo-agent/`
- `_attachments/` 和所有附件目录
- 文件名含 `password`、`密码`、`token`、`secret`、`密钥`、`private key`、`恢复码` 的文件

## 当前实现状态

- 已支持普通目录内搜索、列出和限量读取
- 已支持新建 Markdown 笔记的预览、确认和取消
- 已支持修改已有笔记，插入指向另一笔记的 Wikilink
- 插入位置优先采用用户提示的二级标题，其次采用“相关笔记”等既有章节，否则新建该章节
- 所有写入均需跨消息确认，操作 10 分钟过期
- 修改前校验原文件哈希；并发变化会拒绝提交
- 提交前备份，并通过临时文件原子替换
- 审计记录保存操作元数据，不保存笔记正文

- 手机 `echo-tools` 插件提供 `obsidian_search`、`obsidian_list`、`obsidian_read`
- 原生 MCP 不直接暴露 Obsidian 工具，避免缺少 QQ 事件身份时被绕过
- 手机插件与电脑接口均校验“本人 QQ + 私聊”
- Vault 路径由 `ECHO_OBSIDIAN_VAULT` 配置
- 搜索结果最多 20 条，每条只返回短上下文
- 单次读取最多返回 4000 字符，不提供无限制全文读取
- 日记和归档只在本人私聊中按显式 scope 访问，默认搜索仍不包含它们
- 已完成接口验收：普通范围返回结果，群聊和非本人返回 403，敏感文件拒绝
- 创建写入采用 `obsidian_prepare_create` -> 用户确认 -> `obsidian_commit_create`
- 首阶段只允许创建普通目录下的新 Markdown，拒绝覆盖、删除、移动和重命名
- `obsidian-note-workflow` Skill 已随 `echo-tools` 插件部署到手机

## 不做的事

- 不把整个 Vault 导入手机知识库
- 不读取或上传附件内容
- 不使用 Obsidian Remote、公开 HTTP API 或共享链接
- 不自动整理、重命名、移动或提交 Vault 文件
