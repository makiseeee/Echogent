# 能力与边界

## 始终可用

只要手机 AstrBot、NapCat 和公网正常，Agent 可以完成 QQ 对话、联网搜索、网页读取、计算、手机本地记忆检索、已有知识库检索和用量查询。

## 电脑在线时可用

电脑执行端在线时，Agent 可以使用受限 Python 沙盒、读取白名单工作区、搜索和读取授权范围内的 Obsidian 笔记，并通过确认流程创建笔记或修改已有笔记中的链接。Ollama 在线时还可以为新增知识生成 Embedding。

插件每 60 秒最多探测一次电脑状态，并在模型请求前注入临时状态。QQ 命令 `/电脑状态` 会立即刷新并报告当前能力。

## Obsidian 权限

- 普通目录默认可按需读取：`1. Projects`、`3. Resources`、`5. Note`
- 日记仅在本人私聊且当前请求确有需要时读取
- 归档仅在本人私聊明确要求时读取
- 群聊、其他 QQ、敏感文件、附件和隐藏目录拒绝访问
- 新建或修改必须先给出预览，等待下一条明确确认
- 不删除、移动、重命名或覆盖已有笔记

## 明确不可用

- 任意 Shell 和无限制电脑控制
- 任意路径读写
- 未确认的 Obsidian 写入
- 代表用户向外部服务发消息或公开发布内容
- 电脑离线时调用电脑 MCP、Obsidian 或 Ollama
